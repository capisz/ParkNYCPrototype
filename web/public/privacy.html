NYC Parking Planner

Draft privacy notice

Prototype notice: This repository is not yet an authorized City service. This draft requires NYC privacy and analytics approval before release.

The service is designed to work without an account and does not save a trip history.

Information used for a trip

The destination, optional starting point, arrival time, leave time, and parking preferences are sent to the planning API to calculate a response. The proposed production design uses them for that request and excludes them from product analytics.

Location permission

The website asks for device location only after you select “Use my location.” You can enter a starting point instead. Denying permission does not prevent manual trip planning.

Operations and security

Application logs contain a request identifier, API path without query coordinates, response status, and duration. Exact origins and destinations are excluded. Standard hosting and network systems may process an IP address for security and delivery. The map may request tiles from a configured map provider.

Questions

A City-approved contact and retention schedule must be published before public release.
